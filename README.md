## Resumo
App em React.js + Next.js que consulta dados da API pública "The One API":

- Consulta de todos os personagens da API em tempo real
- Página com detalhes de raça, gênero e reino/origem para cada personagem

## Iniciando
```
# instale as dependências
npm install

# inicie o projeto
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev

# crie um arquivo .env com a chave da API
NEXT_PUBLIC_ONE_API_TOKEN=seu_token_aqui
```
